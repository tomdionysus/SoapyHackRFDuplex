# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone taking part in its issues, pull
requests and other spaces.

In short: be respectful and considerate, assume good faith, keep
discussion about the work, and do not harass anyone.

Report unacceptable behaviour to the maintainer, Tom Cully, at
mail@tomcully.com. Every report is reviewed and answered, and kept
confidential. The maintainer enforces the code as the Covenant's
enforcement guidelines describe, from a warning to a ban from the
project's spaces.
